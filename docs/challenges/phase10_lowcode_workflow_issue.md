# Phase 10 Challenge: Low-Code Workflow vs Engineering Agent

## Problem

Dify and Coze make it fast to assemble a visible workflow, but complex IncidentOps scenarios need more than visual nodes. GraphRAG expansion, tool permission control, dry-run enforcement, and custom evals are hard to validate only through a low-code canvas.

## Why Keep Both

Low-code workflow prototypes help business teams understand the process. The Python engineering version provides deterministic modules, local tests, trace control, and eval automation.

## Key Difference

- Low-code: fast prototype, visual branches, easier stakeholder review.
- Python: testable retrieval, GraphRAG adapters, tool safety, regression eval, versioned SOP docs.

## Interview Framing

Explain Dify/Coze as a workflow shell and the Python project as the safety-critical core. This shows practical judgment: use low-code where it accelerates collaboration, but keep core Agent reliability and observability in code.
